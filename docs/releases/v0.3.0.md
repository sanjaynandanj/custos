## One-line pitch

Custos is a cryptographic audit ledger and policy enforcement layer (PEP) for AI agents. Works with MCP, LangGraph, the Claude Agent SDK, and any tool-calling agent framework. v0.3.0 hardens the authorization surface and repositions Custos around what it actually is: authorization infra for agents, not just an MCP add-on.

## What's new

### Security hardening

- **Dashboard bearer-token auth (opt-in).** `custos serve --token <T>` requires `Authorization: Bearer <T>` on every request; unauthenticated calls get `401`. Both runtimes.
- **Bundle manifest now includes `policies_hash`.** Evidence bundles pin a SHA-256 over the bundled policy snapshot alongside the ledger. Tampering with the shipped policy after export is detectable via `custos verify-bundle`.
- **Policy regexes precompiled at load time.** Regex operators in the native DSL now compile once when the policy is loaded, not per-record. Cuts hot-path overhead and reduces ReDoS surface by rejecting malformed patterns up front.
- **JS Ledger append is documented and tested as single-instance-safe.** The Node ledger's append semantics (single writer per file, exclusive lock, atomic hash-chain step) are now specified and covered by tests; behavior under concurrent multi-writer scenarios is called out explicitly.
- **New threat-model doc.** `SECURITY.md` walks the trust boundaries: what Custos defends against (post-hoc ledger tampering, unauthorized tool calls, unsigned decision claims) and what it does not (compromised gate binary, upstream tool exfiltration on allowed calls).

### Repositioning

- **Custos is a PEP + audit ledger for any tool-calling agent, not just MCP.** README, package descriptions, and site copy all say so. MCP is the highest-value integration surface today; LangGraph, Claude Agent SDK, and the in-process Gate SDK are equal citizens.

### New examples

- **`examples/basic-mcp-policy/`** — the shortest possible policy that shows the DSL's operators in context.
- **`examples/coding-agent/`** — a coding-agent-style policy: allow reads in workspace, deny writes outside a scratch dir, deny `rm -rf`-shaped shell commands, allow HTTPS GETs.
- **`examples/enterprise-data-access/`** — a data-access shape: allow queries on `analytics.*` schemas, deny anything touching `pii.*`, deny writes for non-admin actors.

### New integration docs

- `docs/integrations/claude-code.md` — wrap any MCP server behind Claude Code with the Custos proxy.
- `docs/integrations/langgraph.md` — `gate_tool` + `make_tool_node` walkthrough.
- `docs/integrations/claude-agent-sdk.md` — gating tools defined with the Claude Agent SDK's `@tool` decorator.

## Compatibility

Fully backwards-compatible. Wire format is still `v: 1` — Python-signed ledgers verify in Node and vice versa, exactly as in 0.2.x. No policy migration required.

## Upgrade

```bash
pip install -U custos-mcp
npm install custos-mcp@latest
```
